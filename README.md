# Qualcomm (qualcomm)
Qualcomm is a Fortune 500 company that provides developer APIs and integration capabilities through its developer platform. Qualcomm provides developer APIs and SDKs for mobile computing, 5G connectivity, AI inference, and IoT. The platform supports developers building applications for Snapdragon-powered devices.
